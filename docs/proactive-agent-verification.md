## 复查方式

生产程序：`npm run dev`，登录校园账号并配置 LLM，再到“设置 → 主动助手”。新邮件监控还要求在邮箱设置中允许助手读取。

纯界面预览：`npm run preview:assistant`。浏览器打开本机 4173 端口，始终使用模拟数据。模拟接口不会进入生产 renderer bundle。

隔离原生 QA：`npm run dev:assistant-qa`。临时用户目录、本地模型响应和测试待办，不依赖真实凭据；需要正常的本机图形桌面环境。该入口属于 tests，不是产品中的认证绕过。
