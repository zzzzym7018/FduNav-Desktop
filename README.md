# FduNav

**专为复旦同学开发的桌面校园助手。** 把课程评价、树洞经验、学校通知、课表、待办和邮箱放到同一个工作台，用自然语言查资料、了解课程、安排日常事务。

## 自动查阅课评，让选课前的调查更方便

想了解一门课，不必先想好搜索词，再逐个翻找不同学期的评价。连接旦挞账号并配置模型后，直接在聊天中提问，助手可以按需搜索课程、读取课评，结合树洞讨论整理回答。

例如：

- “这门课的作业量、考核方式和给分怎么样？”
- “帮我比较这两门通识课，重点看课程内容和工作量。”
- “同一门课，不同老师和不同学期的反馈有哪些差别？”
- “我是跨专业选课，先修基础不够会不会很吃力？”
- “查一下江湾校区的相关办事攻略，区分正式要求和同学经验。”

助手可以继续读取相关材料、补充检索，并提供可展开核对的来源。课评保留课程、教师和学期信息，方便判断经验是否适用于自己的情况；正式政策、资格和截止日期需要对照官方资料。

课评和树洞反映的是匿名用户的个人经历，资料数量、发布时间和读取范围会影响结论。自动检索与答案核对能辅助判断，不能保证覆盖全部讨论或代替个人选课决定。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| **课评与校园经验调研** | 自动搜索旦挞课评和树洞、读取评价与帖子上下文，围绕课程内容、工作量、考核、教师风格和校园生活问题整理回答。 |
| **网页检索与来源核对** | 配置网页搜索后，检索公开资料并读取正文；回答支持来源查看，并可进行发布前的证据与引用核对。 |
| **学校通知** | 订阅教务处、研究生院及院系等来源，阅读通知和附件，结合消息偏好生成 AI 摘要并判断相关性。 |
| **课表与日历** | 查询课表、查看个人日程、同步考试安排；课程可尝试打开教学大纲和课程回放，具体取决于学校系统是否提供并开放。 |
| **待办与提醒** | 管理个人待办、导入 eLearning 作业，并设置日程和待办提醒。 |
| **邮箱工作台** | 连接邮箱，查看邮件、文件夹和附件；配置 SMTP 后可撰写、发送和回复邮件。可分别控制是否允许助手读取邮箱。 |
| **对话助手** | 多轮对话、历史会话、上下文压缩、可管理的长期记忆，以及工具执行记录和用量统计。助手提出的日程、待办、记忆等修改通过操作卡片确认。 |
| **校园仪表盘** | 汇总日程、待办、通知和邮件，查看校园卡余额、图书馆人数与天气，并调整组件布局。 |

校园账号、旦挞账号和邮箱分别连接。部分功能受本科生／研究生身份、学校网络、账号权限和上游服务状态影响。

## 密码与凭据如何保护

FduNav 在本机运行，凭据由本机主进程处理。当前实现使用 Electron `safeStorage` 调用操作系统安全存储能力，敏感凭据加密后保存到本机数据库；需要使用时在本机解密。

| 凭据 | 当前处理方式 |
| --- | --- |
| **复旦统一身份认证密码** | 仅用于学校认证流程，不写入账号数据库；认证时按学校公钥加密后提交。登录后保存的是加密的会话 Cookie。需要额外验证时，通过学校登录页面完成。 |
| **旦挞登录密码** | 通过 HTTPS 向旦挞认证服务提交，不作为持久化凭据保存；后续使用加密保存在本机的 access／refresh token。退出登录时移除保存的令牌。 |
| **邮箱密码或客户端授权码** | 因收发邮件需要，在验证连接后加密保存在本机；界面查询账号配置时不返回密码原文。推荐使用邮箱服务提供的客户端专用密码或授权码。 |
| **模型及搜索服务 API Key** | 加密保存在本机；设置页返回“是否已配置”，不返回已保存的密钥原文。 |

系统安全存储不可用时，相关凭据的保存或读取会被阻止；Linux 的 `basic_text` 后端不被接受为可用的安全存储。邮箱 IMAP／SMTP 连接启用 TLS 证书验证，不以忽略证书错误的方式完成连接。

**凭据加密与业务数据保存是两回事。** 对话、通知、日程和执行记录会保存在本机，不能将它们理解为全部经过加密。启用 AI 功能时，问题、相关上下文和所需的通知、课评、树洞或邮件片段会发送到你配置的模型服务；启用网页搜索时，检索词会发送到搜索服务。登录密码不作为聊天内容交给模型处理。

## 开始使用

1. 启动后，在“设置 → 账号”登录复旦账号，按需完成学校要求的额外验证。
2. 配置消息偏好与通知来源，获取适合自己身份的校园信息。
3. 需要 AI 摘要或对话助手时，在“设置 → LLM”启用并配置模型接口、模型名称和 API Key。
4. 需要自动查阅课评或树洞时，在“设置 → 旦挞”登录已有的旦挞账号，然后到聊天页直接提问。
5. 需要公开网页检索时，配置 Tavily API Key；需要邮件功能时，在邮箱设置中添加账号并测试连接。

模型和搜索服务可能产生费用，取决于你选择的服务与账户。学校或社区登录过期后，需要重新验证或登录；校内资料也可能要求相应的校园网络环境。

## 从源码运行

需要符合 `package.json` 要求的 Node.js：`^22.13.0 || >=24.0.0`，以及 npm。建议使用 Node.js 24。

```bash
git clone https://github.com/zzzzym7018/FduNav-Desktop.git
cd FduNav-Desktop
npm install
npm run dev
```

如果依赖安装完成后仍缺少 Electron 运行环境，可按[开发文档](docs/development.md)执行 `npx install-electron` 后重试。

类型检查与应用构建：

```bash
npm run typecheck
npm run build
```

当前打包脚本面向 Windows x64 与 macOS Apple Silicon，建议在对应系统上构建：

```bash
npm run build:win
npm run build:mac
```

安装包输出到 `release/`。请在目标平台安装依赖并构建，以仓库实际提供的构建产物为准。

## 项目结构

```text
src/main/       数据库、认证、学校服务、邮件、模型调用与调研工具
src/preload/    主进程与界面之间的受限桥接接口
src/renderer/   React 页面、组件与样式
src/shared/     类型、校验、跨进程规则与提示词
docs/           开发文档
```

技术栈：Electron、React、TypeScript、Vite 和 SQLite。
